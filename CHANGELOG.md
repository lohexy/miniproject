# (Changelog)

Усі помітні зміни в цьому проєкті будуть документуватися у цьому файлі.

## [1.0.0] - Фінальний реліз
### Added
* Повноцінний CRUD для управління задачами (створення, перегляд, редагування статусу).
* Бізнес-валідація унікальності назви задач (без урахування регістру).
* Механізм розрахунку пріоритетів та дедлайнів через патерн `TaskFactory`.
* Стійке збереження даних (Persistence) у форматі `.json`.
* Resilience: резервне копіювання у `.csv` та Fallback-відновлення при пошкодженні основного файлу.
* Аналітичний модуль для підрахунку статистики (LINQ-агрегація).
* Повне покриття тестами (53 тести: 42 Unit, 11 Integration).

### Changed
* Архітектура рефакторилася з monolithic (`Program.cs`) на багатошарову (Domain, Application, Infrastructure).
* Усунуто "запахи коду" (Magic Strings замінено на Enums).
* Покращено ізоляцію файлової системи у тестах (додано методи `CleanUp`).

### Fixed
* Виправлено падіння програми при відсутності або пошкодженні файлу збереження.
