# Посібник користувача

Вітаємо у Task Manager! Це зручний консольний застосунок для управління вашими задачами, відстеження дедлайнів та аналітики продуктивності.

## Як запустити програму
1. Відкрийте термінал у папці з проєктом.
2. Виконайте команду: `dotnet run --project src/Console/Console.csproj` (або просто `dotnet run`, якщо ви знаходитесь у папці консольного проєкту).

## Головне меню
Після запуску ви побачите головне меню. Для вибору дії просто введіть відповідну цифру і натисніть `Enter`:

* [1] Додати задачу: Програма попросить вас ввести назву задачі, кількість днів до дедлайну та вибрати пріоритет (Високий, Середній, Низький).
* [2] Показати всі задачі: Виводить список усіх ваших поточних задач із їхніми статусами та дедлайнами.
* [3] Змінити статус задачі: Дозволяє перевести задачу в статус `Todo`, `InProgress` або `Done`. *Увага: система не дозволить завершити прострочену задачу, поки ви не зміните її дедлайн!*
* [4] Фільтрація та пошук: Ви можете знайти задачу за ключовим словом, відфільтрувати за конкретним статусом або показати лише прострочені задачі. Також доступне сортування.
* [5] Аналітика: Показує загальний прогрес виконання (у відсотках), задачі, згруповані за пріоритетом, список прострочених задач та 3 найближчі дедлайни.
* [0] Вихід: Безпечно закриває програму.

## Збереження даних
Вам не потрібно зберігати дані вручну! Програма автоматично записує всі ваші задачі у файл `tasks.json` після кожної зміни. Якщо з файлом щось трапиться, програма спробує відновити дані з резервної копії `tasks.csv`.
