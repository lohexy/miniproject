# План залежних розширень (Extension Plan)

Обрано Варіант 3: Async I/O + fault handling + recovery tests.

## 1. Розширення А: Перехід на асинхронний I/O
* Суть: Відмова від синхронного `File.ReadAllText` на користь `File.ReadAllTextAsync` у шарі інфраструктури (`JsonTaskRepository.cs`).
* Результат: Звільнення основного потоку виконання при роботі з жорстким диском. 

## 2. Розширення Б: Механізм Fallback-відновлення (Fault Handling)
* Суть: Додавання блоку `try-catch` для перехоплення `JsonException` та `FormatException` при пошкодженні файлу `tasks.json`. Створення паралельного бекапу в `tasks.csv`.
* Залежність: Ця логіка будується поверх асинхронних методів з Розширення А.

## 3. Розширення В: Гарантія роботи (Testing & Demo)
* Суть: Інтеграція механізму в фінальний демо-сценарій (`DEMO.md`) та написання інтеграційних тестів для перевірки здатності системи піднятися після видалення чи пошкодження файлів.
* Залежність: Перевіряє і підтверджує працездатність Розширення Б на практиці.
