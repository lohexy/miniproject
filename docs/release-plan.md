# План релізу v1.0.0 (Release Plan)

## 1. Що входить у версію v1.0.0
Версія 1.0.0 є стабільним MVP (Minimum Viable Product) консольного Task Manager. До релізу включено:
* Повний CRUD для задач (створення, перегляд, зміна статусів).
* Валідація доменних правил (заборона однакових назв, розумні дедлайни).
* Аналітичний модуль (прогрес виконання, кількість завершених задач).
* Persistence-шар (збереження у JSON).
* Resilience & Fault Handling: автоматичний бекап та відновлення даних із CSV при пошкодженні JSON.
* Повний набір тестів (53 тести, >86% покриття).

## 2. Що переноситься в "після курсу" (Out of Scope)
* Інтеграція зі справжньою реляційною базою даних (Entity Framework Core / PostgreSQL).
* Перехід з Console UI на Web API (ASP.NET Core) або графічний інтерфейс (WPF/MAUI).
* Багатокористувацький режим (авторизація, автентифікація).

## 3. Технічний борг (Допустимий на момент релізу)
* Консольне меню (`Program.cs`) частково використовує синхронні виклики (`.Wait()`) для асинхронних методів репозиторію. У майбутньому варто перевести цикл на `async Task Main`.
* Відсутнє глобальне логування у файл (наприклад, NLog). Наразі помилки обробляються і виводяться лише в консоль.

## 4. Які теми курсу покрито
* Повністю покрито: Основи ООП, абстракції (інтерфейси), колекції та LINQ, обробка помилок (винятки, Fallback), Unit/Integration тестування, патерни Factory та Repository.
* Частково покрито: Асинхронність (реалізовано в I/O файлів, але UI працює синхронно).
