# Звіт про реалізацію розширень (Extension Report)

## Розширення А: Async I/O
* Вхідний артефакт: Синхронний код репозиторію з Lab 35.
* Змінено: Клас `JsonTaskRepository`, методи перетворено на `Task LoadAsync()` та `Task SaveAsync()`.
* Результат: Програма стала асинхронною на рівні доступу до даних. Це підготувало ґрунт для безпечного читання/запису кількох файлів одночасно.

## Розширення Б: Fault Handling (Резервне копіювання)
* Вхідний артефакт: Асинхронний репозиторій з Розширення А.
* Змінено: В метод `SaveAsync` додано паралельну генерацію `.csv` файлу. У `LoadAsync` додано блок `catch (JsonException)`, який викликає `ImportFromCsvAsync()`.
* Результат: Якщо користувач або ОС випадково пошкодить `tasks.json`, програма не впаде з критичною помилкою, а виведе `[УВАГА] Файл пошкоджено! Спроба відновлення...` і завантажить дані з бекапу.

## Розширення В: Демонстрація та Тестування
* Вхідний артефакт: Готовий механізм Fallback (Розширення Б).
* Змінено: Додано секцію "Збереження / Відновлення" у файл `DEMO.md`. Написано інтеграційні тести, що перевіряють I/O збої.
* Результат: Доведено, що архітектура не просто працює в ідеальних умовах, а має реальну відмовостійкість.
