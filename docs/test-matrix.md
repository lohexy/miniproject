# Матриця тестування (Test Matrix)

Ця матриця демонструє відповідність між ключовими сценаріями використання (Use Cases) та конкретними тестами.

| Use Case (Сценарій) | Рівень тесту | Файл з тестом | Покриття негативних сценаріїв (Edge Cases / Fault Handling) |
| :--- | :--- | :--- | :--- |
| Додавання нової задачі | Unit | `ApplicationTests.cs` | Спроба додати дублікат назви (навіть з різним регістром) викликає `DuplicateTaskTitleException`. |
| Розрахунок дедлайнів | Unit | `DomainTests.cs` | Передача від'ємної кількості днів для створення дедлайну безпечно встановлює дату в минулому. |
| Зміна статусу задачі | Unit | `ApplicationTests.cs` | Спроба змінити статус за неіснуючим індексом (-1 або 99) перехоплюється і повертає `false`. |
| Збереження даних (Persistence) | Integration | `InfrastructureTests.cs` | Спецсимволи, українська мова та емодзі зберігаються коректно без втрати даних (UTF-8). |
| Відновлення даних (Fault Handling) | Integration | `InfrastructureTests.cs` | Пошкодження JSON активує парсинг CSV. Злам обох файлів безпечно викидає `ArgumentException`, запобігаючи прихованим багам. |
