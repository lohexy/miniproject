# Vision: Task Management System (Варіант 4)

## 1. Вступ
Даний проєкт спрямований на розробку консольної системи для ефективного планування та відстеження персональних і командних задач. Система дозволяє організовувати робочий процес, контролювати дедлайни та пріоритезувати завдання.

## 2. Опис проблеми
Багато користувачів стикаються з проблемою хаотичного накопичення задач, що призводить до пропущених дедлайнів та неефективного використання часу. Існуючі рішення часто є занадто складними або не забезпечують необхідної гнучкості для швидкої консольної роботи.

## 3. Цільова аудиторія
* Студенти: для планування навчальних завдань.
* Розробники: для ведення списку технічних тасків.
* Менеджери: для швидкого контролю статусу проєктів.

## 4. Ключові Use Cases (Сценарії використання)
Згідно з вимогами, система реалізує наступні основні сценарії:
1.  Створення та класифікація задачі: Користувач додає нову задачу, вказуючи назву, опис, пріоритет (Low, Medium, High) та дедлайн.
2.  Управління життєвим циклом: Зміна статусів задачі (Todo -> InProgress -> Done) з автоматичною перевіркою валідності переходу.
3.  Аналітичний перегляд: Фільтрація та сортування списку задач за критичністю та часом до завершення (використовуючи LINQ).

## 5. Бізнес-логіка (поза межами CRUD)
* Автоматичне підвищення пріоритету задачі, якщо до дедлайну залишилося менше 24 годин.
* Заборона на встановлення дедлайну в минулому часі.
* Розрахунок загального прогресу проєкту на основі завершених задач.
