# Сценарій демонстрації Task Manager (3-5 хвилин)

## Підготовка (до початку демо)
Переконатися, що в папці проєкту лежить підготовлений файл `tasks.json` з тестовими даними (демо-сценарій).

## Крок 1: Старт застосунку (0:00 - 0:30)
* Відкриваю термінал і запускаю: `dotnet run`.
* Показую головне меню.
* Слова: "Вітаю! Мій проєкт — це консольний Task Manager. Я реалізував його з використанням багатошарової архітектури. Зараз програма успішно зчитала дані з файлу збереження."

## Крок 2: Ключовий сценарій (0:30 - 1:30)
* Вибираю пункт меню "Показати всі задачі". Демонструю список.
* Вибираю пункт "Додати задачу".
* Вводю назву "Підготуватися до іспиту", 5 днів до дедлайну, пріоритет High.
* Знову показую список, щоб переконатися, що задача додалася.
* Показую пункт "Аналітика", демонструючи роботу LINQ (відсоток виконання, найближчі дедлайни).

## Крок 3: Негативний сценарій (1:30 - 2:30)
* Слова: "В системі реалізовано захист від помилок та бізнес-валідація."
* Пробую додати задачу з іменем, яке вже існує ("Підготуватися до іспиту").
* Отримую кастомну помилку `DuplicateTaskTitleException`.
* Пробую змінити статус "Простроченої" задачі (яка була в демо-даних) на `Done`.
* Отримую помилку бізнес-логіки: "Не можна завершити прострочену задачу! Спочатку подовжте дедлайн."

## Крок 4: Збереження / Відновлення (Fault Tolerance) (2:30 - 3:30)
* Слова: "Система використовує патерн Fallback для відмовостійкості."
* Закриваю програму.
* Відкриваю файл `tasks.json` і навмисно ламаю його (видаляю половину тексту, щоб JSON став невалідним).
* Знову запускаю програму.
* Програма виводить повідомлення: `[УВАГА] Файл tasks.json пошкоджено! Спроба відновлення...` і успішно завантажує дані з `tasks.csv`.

## Крок 5: Пояснення архітектури (3:30 - 4:30)
* Відкриваю код у Visual Studio / VS Code.
* Показую `TaskService.cs`. Слова: "Тут ізольована вся бізнес-логіка. UI нічого не знає про правила валідації."
* Показую `JsonTaskRepository.cs`. Слова: "Тут інкапсульована робота з файловою системою. Використано інтерфейс IDataStore."
* Згадую про покриття: "Проєкт покрито 53 автотестами (86% покриття)."
